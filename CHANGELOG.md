# Change Log

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).


## v0.2.0 - 2026-09-01

### Added

- Declarative bidirectional mappings between boundary models
- Field references for readable, type-aware mapping declarations
- One-to-many expansion constructs with `expand_rightward` and `expand_leftward`
- Built-in adapters for Pydantic, SQLAlchemy, and `TypedDict`
- Custom adapter registration for additional model frameworks
- Mapping composition for combining reusable mapping definitions
- Structured mapping diagnostics and validation errors
- Standalone reference examples and the guided `betwixt_demo` package
- Zensical documentation covering concepts, features, adapters, comparisons, and API reference
- Published the complete public API for the first full-featured release
